## Context

deep-foundation's applications use `DeepClient` (`select`, `insert`,
`update`, `delete`, `subscribe`, `id`, `can`) and `MinilinkCollection`
(an in-memory store that evaluates Hasura-style `where` locally and keeps
the results of named "applies"). The synced client of ui-links does the
same job with the doublets interface and substitution queries. A
compatible API lets deep-foundation's packages and React hooks run on
link-cli.

## Goal

`createDeepClient(synced)` and a minilinks-like local query engine over a
ui-links storage, with the triplet model of {{U08}}.

## In scope

1. Hasura `where` (`_and`, `_or`, `_not`, `_eq`, `_in`, `_is_null`, relation
   filters `from`, `to`, `type`, `in`, `out`, `typed`) evaluated on the local
   cache, and sent to the server as GraphQL ({{L06}}) or as substitution
   queries.
2. Optimistic ids mapped to real ids (the synced client's temporary
   addresses).
3. Values (`strings`, `numbers`, `objects`) as links.
4. `can(object, subject, action)` from the permission layer.

## Acceptance criteria

- A subset of deeplinks' minilinks tests, ported, passes.
- deepcase's main view loads through it from `clink --serve`.
