## Context

`PinnedTypesDecorator` pins types as points `(a: s a)` at fixed addresses.
The associative architecture of deep-foundation needs types that are
themselves values of types, to any depth, and links of several types at once:

```
Type -> SubType
SubType -> SubType
SubType -> Value
```

The permission layer ({{L02}}) checks rules against this hierarchy, so it is
the first step.

## Goal

A decorator that keeps a type hierarchy in the links themselves, with
recursive sub-typing and multiple inheritance, in C# and Rust.

## In scope

1. The model (the one of `@link-foundation/ui-links`' `typeSystem`):
   - the type of a link is its source: `(v: S x)` is a value of type `S`;
   - the root is the point `(Type: Type Type)`; a sub-type of `T` is
     `(S: T S)`, a value of `T` that points at itself (this generalises the
     pinned types, which are sub-types of one common source);
   - more parents (multiple inheritance) are pairs `(p: S T2)` marked by a
     link `(m: Extends p)`, where `Extends` is a type too.
2. Queries: `TypeOf`, `IsType`, `ParentsOf`, `AncestorsOf`, `IsA(link, type)`
   (the type itself or of it), `IsOf(link, type)` (strictly of it), robust to
   cycles.
3. Writes: `Define(parent, params more)` and `Instance(type, target)`.
4. CLI: nothing new is required; the hierarchy is ordinary links, so queries
   and LiNo import/export already handle it. Document it in the README.

## Out of scope

Permissions ({{L02}}), triplets ({{L04}}).

## Step-by-step plan

1. Port `packages/ui-links/src/types.js` and its tests
   (`packages/ui-links/tests/permissions.test.js`, "types") to C# and Rust.
2. Add `TypesDecorator` next to `PinnedTypesDecorator`, unsealed, with the
   queries above; keep `PinnedTypes` working (its types are sub-types).
3. Add tests for depth 3+, diamonds and cycles.

## Acceptance criteria

- `Define(Type)`, `Define(User)`, `Define(Note, Doc, Public)` build the
  hierarchy as links; `IsA(news, Doc)` and `IsA(news, Public)` are true for
  a value of `Note` that also extends `Public`.
- A cycle (`A` extends `B`, `B` extends `A`) terminates.
- C# and Rust pass the same test cases.
