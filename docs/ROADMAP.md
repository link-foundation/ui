# Roadmap

This roadmap was planned in
[the planning issue](https://github.com/link-foundation/ui/issues/1). The
[issue 1 case study](case-studies/issue-1/README.md) explains every
decision, and [`ARCHITECTURE.md`](ARCHITECTURE.md) describes the target
design. The file is generated by
`experiments/issue-1/create-roadmap-issues.mjs` from
`docs/case-studies/issue-1/roadmap/issues/`.

Bugs come first. Features can be worked on in parallel as soon as every
issue in their "Blocked by" column is closed; GitHub shows the same
relations as native issue dependencies.

Tracking issue: [#75](https://github.com/link-foundation/ui/issues/75) (Roadmap: associative UI framework).

## Issue 101 — associative links: doublets MVP, then triplets and Deep

[Issue 101](https://github.com/link-foundation/ui/issues/101) asked for
associative storages behind one interface, a synced client and a server
with permissions stored as links. Its doublets MVP is done:
`packages/ui-links` and the links storage of `packages/ui-store`. The rest
is planned below, here and in link-cli; the
[issue 101 case study](case-studies/issue-101/README.md) explains every
decision. This section is generated by
`experiments/issue-101/create-issues.mjs` from
`docs/case-studies/issue-101/roadmap/issues/`.
