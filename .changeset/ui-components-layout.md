Add `@link-foundation/ui-components` with the layout and windowing kinds of ui-dom: `stack` and `grid` (thin wrappers of flexbox and grid with checked track lists), `split` (WAI-ARIA window splitter, min/max/collapsible panes, sizes remembered as Links Notation), `tab-group` (WAI-ARIA tabs with close, reorder, drag and overflow menu), `dock` (regions, move, float, close and restore panels, layout saved and read back as Links Notation), `window` (movable, resizable, kept inside the viewport) and `app-shell` (bottom bar, rail or drawer by breakpoints). A layer manager orders every floating surface so a raised window never covers a modal; `layout.css` styles them all.
