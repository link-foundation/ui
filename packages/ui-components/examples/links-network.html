Links network

Click a link or point to select it; Shift+click adds to the selection. Drag a point to pin it, drag the background to pan, and use the wheel to zoom.

Keyboard: Home selects the first point. Arrows move to the nearest neighbour in that direction; Enter activates, Escape clears selection. Use +/− to zoom, 0 to reset, Alt+arrows to pan and Shift+F10 for the context menu.

Select a link, then press Enter to inspect it.
